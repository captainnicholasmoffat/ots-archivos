# OTS Archivos

OTS Archivos is a private tool for one person: Cap'n Nick (Old Time Sailors LLC). It lets his own AI assistant read
files in his own Google Drive accounts, so it can find the band's artwork, video and documents. It is not offered to
anyone else.

## Privacy

- **What it reads.** Only files in the Google accounts of the owner, Cap'n Nick, that he connects himself. The access
  is read-only (Google's `drive.readonly` permission): it can look at and download files, never change, share or
  delete anything.
- **Who sees it.** Only the owner and the AI assistant working for him. Nothing is sold, shared with third parties or
  used for advertising.
- **Where it is kept.** The access key is kept privately by the owner. Files are copied only when a task needs them,
  and are kept only as long as that task needs them.
- **How to stop it.** The owner can remove the access at any time at
  [myaccount.google.com/permissions](https://myaccount.google.com/permissions).
- **Google user data.** Use of information received from Google APIs follows the
  [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including
  the Limited Use requirements.
